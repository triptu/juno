Get Juno

Download for Mac

  1. Install it

    Download the file ending in -arm64.dmg and drag Juno to Applications. Juno is unsigned. If macOS blocks the first open, choose Open Anyway in System Settings › Privacy & Security, or run:

    xattr -d com.apple.quarantine /Applications/Juno.app

  2. Connect Slack

    Sign in to Slack's desktop app first. In Juno, choose "Use the Slack app's session" and allow the macOS password prompt.

  3. Add an AI key

    Optional. Add an OpenRouter key in Settings › Juno to turn on titles, drawings, notification checks and Home. These features send the Slack text they need to OpenRouter, or to whichever provider you choose.

Caught up

Juno has no server of its own. Your Mac talks to Slack directly, and AI only runs with a key you add.
