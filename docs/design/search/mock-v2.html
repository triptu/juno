The search mark

Today the mark is a tint of the accent, the colour that also draws the @you chip and every link, so a match inside a mention or next to a link does not stand out. Each option below is the same in every accent. The message holds a mention of you, a mention of someone else, a link with the word in it, and inline code. The last word ("Kestrel's") is the reader's current match.

Measured (WCAG 2, sRGB; page light #FCFBF7, dark #1B1916; script in /Volumes/AgentWork/scratch/search-marks/c.mjs). Body text on the page is 15.55:1 light and 14.71:1 dark. A link inside a mark takes the mark's text colour and keeps its underline, since coral on yellow falls to 4.8:1.

Recommended: Find yellow. It is the colour every Mac app (Safari, Mail, Xcode, Preview) uses for "here is what you searched for", and Slack uses it too, so it needs no learning. It has no hue in common with coral, teal, cyan, claret, emerald, midnight or ink, and does not look like inline code. The current match in the reader is a brighter yellow, and in dark it turns to dark text on bright yellow, as macOS does. One mark everywhere: results, the reader and Find in topic. With the Marigold accent the @you chip is yellow too, but it is a solid pill with bold text, while the mark is a pale wash on plain text (bottom row).

Four ways to draw a result

The same eight matches for "kestrel", newest first, in a 560 px column cropped at 980 px. The third match is selected. All use the Find yellow mark.

1, snippet. Today's row made taller: sender, place and time on one line, three lines of text from just before the match. The most results per screen, but a long message is still cut, the thread's title is gone, and bot reports look like people's notes. 2, message (recommended). A quiet place line (the pill and, for threads, Juno's title), then the message exactly as the topic draws it: photo, name, time, the whole text, files, reactions and the reply line. A long message folds with the match kept in view. Matches from one topic in a row share one place line. 3, card. Slack's look: a bordered card per message with the channel in the header. Clear edges, but the borders repeat down the whole page, and the channel turns into small grey text. 4, with neighbours. The message with one line before and after. Good context when Juno holds the conversation, but for the rest it costs one history call per result, and the faint lines compete with the match.

A quieter filter row

Filters already live in the field as chips, so the four menus beside it repeat them. Three proposals, from today's row to none at all.

Recommended: B. Three controls instead of seven. Filter opens one menu (From, In, Date, Has, each with Slack's counts); a picked filter becomes a chip in the field, where you can see and remove it. "Hidden: apps, automated" says what is hidden in plain words and opens a two-item menu; when both are shown it reads "Show all" and goes quiet. The sort keeps its place. C moves the controls into the field: the cleanest, but the field gets crowded once chips and a long query are in it, and the hidden state is easy to miss.
