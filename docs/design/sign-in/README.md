# Sign-in page

The approved direction for the sign-in page (10-21): direction a, "Abstract calm", of three mockups. `mockup-a-light.png` and `mockup-a-dark.png` are its screenshots. The copy in them is an earlier draft; SPEC section 4, "Sign-in", has the final copy, and `docs/design/inventory.md` 1.1 has the built values.

What the page took from the mockup: everything centred; the highlights as a two-column list with labels right-aligned; large Tide pebbles drifting off both edges with one accent band per side; a faint accent wash behind the title; the theme and accent controls in one row at the foot. What it dropped: the paper-grain filter (its paint cost), and the "Theme" and "Accent" labels.
