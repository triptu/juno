- 10-24 14:12 · Notification hours per day · Tushar asked for different notification hours on weekdays and weekends, as Slack allows. Each day is now off or has its own from and to, as Slack's Custom schedule. The saved hours keep one set of days with a shared from and to and add `dayHours` for days that differ, so hours saved by older versions read unchanged and older versions read the shared hours. Settings keeps the one row while every day has the same hours and adds Different hours on some days. Slack gets `every_day` or `weekdays` when the hours fit them, else `custom` per day. Active hours stay one set.
