- 11-07 19:56 · r2-outbox · A post whose file will never finish staging (the composer could not read it, or a restart lost its bytes) goes on without that file: the row fails with `file_not_staged` as before, and Retry sends what the row shows · Retry on such a row could never succeed, since nothing can bring the bytes back, so the choice was to hide Retry for this code or to make Retry truthful. Hiding it needs the view to learn the failure code and leaves the user with Delete draft only, which also loses the text. Dropping the file keeps the text and the other files, and the failed row shows exactly what Retry will send. A restart alone does not lose a file: one whose declared bytes are all on disk is completed again (`Staging.recover`).
