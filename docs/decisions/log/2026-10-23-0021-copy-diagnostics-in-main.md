- 10-23 00:21 · copy-diagnostics-in-main · Copy diagnostics is written to the clipboard in main (`app.copyDiagnostics`), as Copy log is: About sends its report and outbox counts (at most 16 KB), and main adds the macOS version and each process's last 50 warnings. Sending the logs back through `clipboard.writeText`, then capped at 2048 characters, made the copy fail on any install with a few dozen warnings. `app.logDiagnostics` is removed, and main logs every failed IPC request with its channel and error type.
