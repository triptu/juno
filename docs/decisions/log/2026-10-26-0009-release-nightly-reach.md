- 10-26 00:09 · A release needs a passing nightly tier: each nightly file passed at an ancestor and no change since reaches it (`affected --wide`, scripts left out), or the release runs it (`verify:main --release`, or `--nightly-reach-only` when a full run already covers the tip) · Nightly runs are not scheduled, so without this a release could ship code no nightly test has seen; rerunning only what the changes reach keeps the release run short.
