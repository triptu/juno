- 10-27 18:56 · Drafts remember what was sent · Each send records the draft whose text went, by Slack's id or, while a create is unanswered, its `client_msg_id`, with Juno's texts that can be on it, so a version with one of them never brings the text back whatever the clocks say, and a late create answer or echo is deleted instead of linked. A version with another text is another device's change: it stays as the place's draft (or for ⌘Z under newer typing). Before deleting a sent draft Juno reads it with `drafts.info` and leaves it on any change, since a leftover is recoverable and a deletion is not; a change in the moment between that read and the delete can still go, as Slack has no conditional delete. Recorded sends go once Slack has the draft gone, after 30 days, or past the latest 20 per topic.
