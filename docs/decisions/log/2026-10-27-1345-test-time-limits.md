- 10-27 13:45 · Test time limits · Each lane's default timeout is its limit on one test's time (`@juno/testing/limits`): unit 5 s, DOM 15 s, browser 20 s, Electron 30 s, set above the slowest healthy test on the shared laptop, whose load moves a test's time by about two. A longer timeout needs a `// Slow:` reason the lint checks; setup a test does not own (a synced start, now also for named seeds) is outside its time; full runs record every test's time and list each lane's ten slowest.
