- 11-01 15:00 · site-features-tour · The site's features section swaps the whole window for that feature's state, instead of a crop over it, and runs a tour while in view · Tushar found the crops read as part of the window behind them and the labels did not look like something to hover. Each state is the same window rendered in that state (Search tab, Settings page, palette over the window), about 1.5 MB per theme, loaded one by one when the section is near. The tour moves every 3.5 s and stops for good at the first hover, focus or tap.
