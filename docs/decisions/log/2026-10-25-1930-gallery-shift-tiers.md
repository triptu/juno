- 10-25 19:30 · gallery-shift-tiers · Orchestrator decision, reversible: the gallery's layout-shift guard runs in two tiers. A computed tier (`computed-shift.spec.ts`) checks every state on every run with forced pseudo-class styles, synthetic events and the guard's box comparison, about a fifth of a second a state on two cores, and also carries the cursor rule and whole-pixel message rows. The real-input walk runs on an ordinary run only for states whose own component changed (at most 60), and over every state with `GALLERY_SHIFT_ALL=1` (`verify:main --nightly`, `--no-cache`); releases use the ordinary run. Why: the walk costs about two seconds a state, and full verification should take one to two minutes. It trades same-commit detection of shifts that exist only mid-transition, wait for a frame or ResizeObserver, or come from real-input defaults, in states reached only through a shared file, for speed; the nightly walk still finds those.
