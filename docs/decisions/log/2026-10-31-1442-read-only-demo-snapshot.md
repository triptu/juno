- 10-31 14:42 · The read-only demo answers the renderer from an exported snapshot · The demo is the production renderer with no engine: `@juno/state/demo` is an `RpcClient.Protocol` that answers each request in the page from `snapshot.json`, and a bridge with nothing behind it answers `window.juno`. The snapshot comes from the real engine against the demo seed with the fake AI's jobs on, read route by route through a recording client (`@juno/state/demo-capture`), not recorded from clicks, so every filter, scope and whole topic is in it. Answers are stored encoded by their route's schema and checked on the way, so a contract change fails the export rather than the page. A request with no answer is a miss the test fails on, never a made-up value.
