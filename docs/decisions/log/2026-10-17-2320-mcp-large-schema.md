- 10-17 23:20 · mcp-large-schema · Juno never works from part of a connection tool's schema. Schemas stay deferred (`find_tools` loads one when the model is about to call the tool), not sent as tool declarations: the declarations stay fixed and cached, and a schema costs only in runs that use it. A schema answer is marked `whole`, so it skips the 2 KB page and the 20 KB attachment notice, up to 48 KB (`limits.wholeResult`, within the 64 KB active run). Past that, or when Juno can't check arguments against it, Juno says so in one line. `$defs` now resolve.
