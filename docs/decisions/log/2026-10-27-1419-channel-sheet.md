Create waits for Slack and stays open on a refusal; Save closes at once, shows a rename everywhere, puts the old name back if Slack refuses, and offers Undo for what Slack changed. Slack's own client asks `permissions/info` per channel; a menu cannot wait for that, so `channelEditRights` reads the store (role, general, Slack Connect, creator, archived, membership) and errs towards showing. These calls are not persisted outbox rows: each settles while the command waits (research `slack-channels.md`).
