- 10-25 19:52 · Cache the React Compiler pass per file · The compiler's Babel pass was about 60% of every cold renderer, web and gallery build. `apps/desktop/react-compiler.vite.ts` runs the same transform and keeps each file's result under a hash of its path, source, Vite root, options and `bun.lock`, in the runner's shared `/cache/builds` or the temp folder. Outputs were byte-identical with and without it; a desktop build that misses the build cache went from 35.6 s to 20.4 s, web 28.6 to 13.1 s, gallery 21.7 to 10.0 s. Releases turn it off (`JUNO_REACT_COMPILER_CACHE=0`).
