- 10-14 21:40 · orchestrator · Merged browser-like navigation. Choices made in the build: the sidebar drag writes a plain width on the sidebar box (a CSS variable on the shell cost 4.7 ms of style recalculation per frame; now p95 5.1 ms); width and hidden state live in `launch.json` so the first frame has them; a drag below 200px hides the sidebar; swipe is the three-finger one (Electron does not see two-finger swipes); Open in Slack on a thread opens its channel, since Slack has no documented thread deep link; bulk close items are disabled when they would close nothing.
